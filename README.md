# 从几何到逻辑：基础教育中的逻辑提取指南

## 项目愿景
本项目旨在通过中国义务教育阶段熟悉的“欧氏几何”知识，引导读者平滑过渡到形式逻辑（命题逻辑与一阶逻辑）。我们希望证明：逻辑并非大学才接触的新学科，而是早已潜伏在初中几何的证明题中。

## 目标读者
- 对逻辑学感兴趣但觉得教材过于抽象的学习者。
- 希望理清数学思维与逻辑思维关系的初高中学生及大学生。
- 认为“中国学校不教逻辑”并希望寻找教育切入点的人。

## 目录结构
- `src_md/`: 包含各章节的具体 Markdown 内容及 `SUMMARY.md`。
- `book.toml`: mdBook 配置文件。
- `src/main.rs`: 用于构建本书的 Rust 程序。

## 如何构建
本项目使用 Rust 编写的构建脚本结合 `mdBook` 库进行构建。

1. 确保已安装 Rust 环境。
2. 在根目录下执行：
   ```bash
   cargo run
   ```
3. 构建完成后，静态网页将生成在 `book/` 目录下。

## 目录预览
- `outline.md`: 本书的详细逻辑架构与大纲。
- `chapters/`: 包含各章节的具体内容。
