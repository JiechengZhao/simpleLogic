# 第1章：命题逻辑——几何证明的连接方式

我们在做几何证明题时，经常会用到“因为……所以……”或者“由已知条件得……”这样的表达。这些连接词背后的规律，就是逻辑学研究的对象。在本章中，我们将把注意力从具体的图形（比如线段、角）暂时转移到事实之间的连接方式上，这套体系在逻辑学中被称为“命题逻辑”。

本章的主要内容包括：

1. **命题与已知条件**：了解什么是逻辑命题，以及如何用符号记录“在特定条件下，某个事实成立”这一状态。
2. **常用的逻辑连接词**：我们将学习如何处理“如果……那么……”（蕴涵）、“并且”（合取）、“或者”（析取）以及“不成立”（否定）这几种关系，并掌握它们的使用规则。
3. **常用的推理方法**：介绍在数学证明中非常实用的技巧，比如分类讨论和反证法，看看它们在逻辑层面是如何运作的。
4. **符号化与计算**：最后，我们会学习如何给逻辑表达式规定运算顺序，以及如何像做代数题一样，通过简单的规则去简化和计算逻辑命题。

通过这些内容，你会发现复杂的证明其实是由一些简单的逻辑单元组合而成的。掌握了这些规律，能帮助我们更清晰、更严密地梳理推导思路。
