# 1.2 逻辑连接词：构建命题的积木

为了描述复杂的几何关系，我们需要将原子命题通过逻辑连接词组合起来。

- **蕴涵 ($\to$)**：几何定理的标准格式。“如果 $P$，那么 $Q$”。如“对顶角 ($P$) $\to$ 相等 ($Q$)”。
- **且 ($\land$)**：条件的合成。如“$AB=AC$ $\land$ $\angle A=90^\circ$”描述了一个等腰直角三角形。
- **或 ($\\lor$)**：分类讨论的基础。如“$\angle A=90^\circ \lor \angle B=90^\circ \lor \angle C=90^\circ$”表示这是一个直角三角形。
- **非 ($\\neg$)**：状态的否定。如 $\neg(L_1 \parallel L_2)$ 表示两条直线不平行。
- **当且仅当 ($\\leftrightarrow$)**：双向等价. 如“$AB=AC \\leftrightarrow \angle B = \angle C$”。
