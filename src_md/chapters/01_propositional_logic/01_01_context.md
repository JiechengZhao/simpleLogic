# 1.1 命题与上下文：知识的增长过程

在几何证明中，结论并非凭空产生，而是被“挖掘”出来的。逻辑学通过“命题”与“上下文”这两个概念，精确地捕捉了这种从已知到未知的发现过程。

## 命题（Proposition）

**命题**是逻辑世界里的原子。它是一个陈述句，表达了一个具体的、可判定真伪的事实。

在几何中，命题随处可见：
- $P_1$: 线段 $AB = AC$。
- $P_2$: $\triangle ABC$ 是等腰三角形。
- $P_3$: $\angle B = \angle C$。

### 上下文的概念

**上下文**（通常用希腊字母 $\Gamma$ (Gamma) 表示）是命题的**集合**。它代表了我们当前的“规则边界”与“已知事实”。

我们可以把上下文想象成推导的“活动范围”。在数学中，这种限制非常常见：比如在引入复数之前，我们的上下文仅限于实数，此时“对 $-1$ 开根号”是无意义或不被允许的。这种**由初始命题和规则构成的边界**，就是上下文。

虽然很多教材为了形象化会称之为“世界”，但在初中数学的语境下，它更像是我们做题时黑板上所有已知条件、定义和公理的总和。

### 例子 1：欧几里得上下文
最著名的上下文莫过于欧几里得平面几何。它的基础由五条公理构成：
1. 从一点向另一点可以引一条直线。
2. 任意线段能无限延伸成一条直线。
3. 给定任意线段，可以以其一个端点作为圆心，该线段作为半径作一个圆。
4. 所有直角都相等。
5. 若两条直线都与第三条直线相交，并且在同一边的内角之和小于两个直角，则这两条直线在这一边必定相交。

这五条公理本质上也是五个命题，它们共同构成了上下文 $\Gamma_{Euclid}$。

### 例子 2：球面几何上下文
如果你在地球仪上画三角形，你会发现欧几里得的规则失效了。球面几何是一个著名的例子：我们保留欧几里得的前四条公理，但把第五条（平行公理）替换掉——在球面上，不存在不相交的平行线，任何两条“直线”最终都会相碰。通过这种“替换规则”的操作，我们就从一个上下文切换到了另一个完全不同的逻辑边界。

### 例子 3：初中代数上下文
你在解代数题时，其实也身处一个特定的上下文中。这个上下文 $\Gamma_{Algebra}$ 包含了一些基本规则（比如加法交换律 $a+b=b+a$）以及数字的定义。逻辑学家皮亚诺（Peano）曾为这种算术系统整理过一套公理，规定了数字是如何从 0 开始“生长”出来的。借助这套公理系统，我们可以通过逻辑构建严格地构建我们平时使用的代数系统。但这是大学数学专业课程，这里我们不做展开。

## 判定（Judgment）
为了表达一个命题在特定的上下文中是成立的，逻辑学引入了一个核心符号：$\vdash$。

$$ \Gamma \vdash P $$

这个表达式被称为一个**判定（Judgment）**。我们将它读作： **“在上下文 $\Gamma$ 中，命题 $P$ 成立。”**

判定描述的是一种**知识**：即在当前的规则和事实（$\Gamma$）支持下，$P$ 已经是确凿无疑的了。
- 例如：$\Gamma_{Euclid} \vdash \text{三角形内角和} = 180^\circ$。

### 不同的上下文，不同的判定
结论的成立与否取决于上下文。如果改变上下文，原本成立的判定可能就不再成立。
例如在**球面几何**（非欧几何的一种）中，平行公理不成立。在这个新的上下文 $\Gamma_{Sphere}$ 中：
- $\Gamma_{Sphere} \vdash \text{三角形内角和} \ne 180^\circ$
- 事实上，在球面上，三角形的内角和总是大于 $180^\circ$，即：$\Gamma_{Sphere} \vdash \text{三角形内角和} > 180^\circ$。


## 案例：等腰三角形证明中的事实挖掘

我们通过一个具体的证明题，观察我们如何在同一个 $\Gamma$ 中确认越来越多的判定。

**目标**：在上下文 $\Gamma$ 中（包含几何公理及已知条件 $AB=AC$），确认结论 $\angle B = \angle C$。

1. **初始判定**：根据题设，直接做出判定：$\Gamma \vdash AB = AC$。
2. **引入新判定**：作顶角平分线 $AD$。根据公理，确认新判定：$\Gamma \vdash \angle BAD = \angle CAD$。
3. **确认共有属性**：观察图形得到判定：$\Gamma \vdash AD = AD$。
4. **触发推理规则**：上述三个判定满足了 **SAS (边角边) 全等判定规则**。于是，我们得到了一个更强的判定：$\Gamma \vdash \triangle ABD \cong \triangle ACD$。
5. **抵达最终目标**：根据全等三角形的性质，确认最终判定：$\Gamma \vdash \angle B = \angle C$。


## 知识的累积性（Accumulation）

在上述过程中，我们会发现一个细节：**一旦某个命题在 $\Gamma$ 中成立，它就永远成立。**

当我们进行到第四步确认全等时，第一步中关于边相等的判定并没有消失。这种性质在逻辑学中被称为**累积性**。它意味着我们的知识库是**只增不减**的。
- 即使你在证明过程中又画了更多的辅助线，之前那些已经成立的判定依然稳如泰山。
- 在同一个 $\Gamma$ 下，你每确认一个新事实，你对当前这个逻辑空间的认知就增加一分，而旧的认知永远不会被推翻。

这种性质对人类文明至关重要。这意味着如果我们昨天通过推理得到了一个结论，只要前提和规则（上下文）没有改变，那么这个结论在今天、明天甚至一千年后依然成立。这是人类能够基于推理和数学系统进行大规模知识传承的核心原因。在文学艺术的世界里，“一千个读者心中有一千个哈姆雷特”；但在推理的世界里，只要上下文确定，哈姆雷特永远只有一个。
