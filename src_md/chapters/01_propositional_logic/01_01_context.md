# 1.1 命题与上下文（Context）

**命题（Proposition）**是一个陈述事实的语句。在几何学中，命题具有明确的含义，例如：
- $P_1$: $AB = AC$（线段相等）
- $P_2$: $\angle ABC = \angle ACB$（角相等）
- $P_3$: $L_1 \parallel L_2$（直线平行）

**上下文（Context）**是命题的集合，通常用希腊字母 $\Gamma$ 表示。它代表了我们在某一时刻所掌握的所有已知信息。在一个典型的几何证明中，$\Gamma$ 的构成如下：
1. **公理（Axioms）** : 系统中预设为真的命题集（如“等量代换”）。
2. **题设（Premises）** : 题目给定的特定条件（如“已知 $\triangle ABC$ 是等腰三角形”）。
